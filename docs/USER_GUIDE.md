## Getting Started

### Launching the App

When you first open Card Game Scorekeeper, you'll see the home screen with:
- A trophy icon at the top
- The app title and tagline
- Action buttons to start a new game or view history

### First Time Use

1. **Start New Game**: Tap the "Start New Game" button
2. **Add Players**: Enter names for 2-8 players
3. **Begin Playing**: Start tracking scores immediately

## Creating Your First Game

### Step 1: Add Players

1. Tap "Start New Game" from the home screen
2. Enter player names in the text fields
   - Minimum: 2 players
   - Maximum: 8 players
3. Each player is automatically assigned a unique color
4. Tap "Create Game" to begin

### Step 2: Understanding the Interface

After creating a game, you'll see:
- **Scoreboard**: Current scores and rankings
- **Round Counter**: Current round number
- **Player Cards**: Individual player info with colors
- **Action Buttons**: Add scores, view history

## Playing a Game

### Recording Scores

#### Method 1: Direct Score Entry

1. Navigate to the scoreboard
2. Tap "Add Scores" button
3. Enter scores for each player
4. Confirm the entries

#### Method 2: With Predictions

1. Before the round, tap "Enter Predictions"
2. Each player enters their predicted score
3. Play the round
4. Enter actual scores in "Results"
5. The app calculates accuracy automatically

### Viewing Current Standings

The scoreboard shows:
- **Player Names**: With assigned colors
- **Current Scores**: Running totals
- **Rank**: Current position (1st, 2nd, 3rd, etc.)
- **Statistics**: Games played, predictions, accuracy

### Completing a Game

1. Play all desired rounds
2. View final statistics
3. Tap "End Game" to mark as complete
4. Optionally archive for future reference

## Managing Multiple Games

### Accessing Game List

1. From the home screen, tap the **list icon** (top-right)
2. Or navigate to Settings → Games

### Creating Additional Games

1. Open the game list
2. Tap the **+ icon** in the app bar
3. Follow the same creation process
4. New game becomes active automatically

### Switching Between Games

1. Open the game list
2. Tap any **active game** to switch to it
3. Previous game is auto-saved
4. Resume play immediately

### Archiving Games

**Why Archive?**
- Keep completed games for reference
- Reduce clutter in active game list
- Preserve game history

**How to Archive:**
1. Open game list
2. Tap the **⋮ menu** on a game card
3. Select "Archive"
4. Game moves to archived section

**Unarchiving:**
1. Scroll to "Archived Games" section
2. Tap the **⋮ menu**
3. Select "Unarchive"
4. Game returns to active list

### Deleting Games

**Warning:** Deletion is permanent and cannot be undone!

1. Open game list
2. Tap the **⋮ menu** on a game card
3. Select "Delete"
4. Confirm deletion in dialog

## Using Undo/Redo

### When to Use Undo

- Accidentally entered wrong score
- Added scores to wrong round
- Want to change player names
- Need to remove a round

### How to Undo

1. Tap the **Undo button** (⟲ icon)
2. Action is immediately reversed
3. Can undo up to 50 recent actions
4. Undo button disables when no history

### How to Redo

1. After undoing, tap **Redo button** (⟳ icon)
2. Restores the undone action
3. Redo history clears after new action

### Undo History

The app remembers:
- Last 50 state changes
- Score additions
- Round completions
- Player modifications

**Note:** Undo history is cleared when:
- Switching between games
- Closing the app
- Starting a new game

## Customizing Appearance

### Accessing Theme Settings

1. Tap the **settings icon** (top-right on home)
2. Or navigate to Settings from menu

### Theme Options

#### Light Mode
- Clean, bright interface
- GitHub-inspired color palette
- Best for well-lit environments

#### Dark Mode
- Easy on the eyes
- Reduced blue light
- Perfect for evening use
- GitHub dark theme colors

#### System Theme (Recommended)
- Automatically follows your device
- Switches with system settings
- Seamless day/night transition

### Changing Themes

**Manual Switch:**
1. Open Settings
2. Disable "Use System Theme"
3. Tap Light or Dark button
4. Theme changes immediately

**Enable System Theme:**
1. Open Settings
2. Toggle "Use System Theme" on
3. App follows device setting

### Theme Persistence

Your theme preference is:
- Saved automatically
- Remembered across sessions
- Device-specific (doesn't sync)

## Tips & Tricks

### Faster Score Entry

- Use predictions to track accuracy
- Enter scores immediately after each round
- Review history if uncertain about past scores

### Organization

- Name games descriptively (e.g., "Friday Night Game")
- Archive completed games regularly
- Delete games you no longer need

### Accuracy Tracking

- Encourage players to make predictions
- Review prediction accuracy in statistics
- Use trends to improve future predictions

### Performance

- Limit active games to 5-10 for best performance
- Archive old games to reduce clutter
- Use undo sparingly (it uses memory)

### Keyboard Shortcuts (Planned)

Future versions will support:
- `Ctrl+Z` / `Cmd+Z`: Undo
- `Ctrl+Y` / `Cmd+Y`: Redo
- `Ctrl+N` / `Cmd+N`: New game

## FAQ

### General

**Q: How many players can I have?**  
A: 2-8 players per game.

**Q: How many games can I create?**  
A: Unlimited! But we recommend archiving old ones for performance.

**Q: Is my data saved?**  
A: Yes, all data is saved locally on your device automatically.

**Q: Can I export my games?**  
A: Not yet, but it's planned for a future update.

### Scoring

**Q: How does prediction accuracy work?**  
A: If you predict 5 and score 5, it counts as accurate. Otherwise, inaccurate.

**Q: Can I edit past scores?**  
A: Use undo to go back and change recent entries. Direct editing coming soon.

**Q: What if players tie?**  
A: The app shows them as tied in the rankings.

### Technical

**Q: Does this work offline?**  
A: Yes! All features work completely offline.

**Q: Where is my data stored?**  
A: Locally on your device using Hive database.

**Q: Is my data backed up?**  
A: Currently no automatic backups. Cloud sync is planned.

**Q: Which platforms are supported?**  
A: Android, iOS, Web, Windows, macOS, and Linux.

### Troubleshooting

**Q: App won't start**  
A: Try restarting your device. If issues persist, reinstall the app.

**Q: Scores aren't saving**  
A: Check device storage. The app needs write permissions.

**Q: Theme won't change**  
A: Ensure "Use System Theme" is disabled for manual control.

**Q: Lost undo history**  
A: Undo history is cleared when switching games or closing the app.

### Features

**Q: Can I customize player colors?**  
A: Not yet, but it's planned for a future update.

**Q: Can I rename players mid-game?**  
A: Not directly, but you can use undo to go back and recreate with correct names.

**Q: Is there a timer feature?**  
A: Not yet, but it's on the roadmap.

**Q: Can multiple devices sync?**  
A: Not yet. Cloud sync is planned for a future release.
